# Deployment helpers

Each helper renders or validates private inputs; none applies serving resources
unless its table row says so. Run them from the repository root with the
variables named in the deployment guide. Keep outputs outside both checkouts.

| Script                        | Purpose                                                                                                  | Key inputs                                                                                                        |
| ----------------------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `prepare-inputs`              | Write the private Helm values, Installation, bootstrap PVC, and egress inputs for the IPv4 test profile. | `OCC_INPUT_DIRECTORY`, `OCC_CONSOLE_HOST`, `OCC_ADMIN_EMAIL`, `CONTROLLER_IMAGE`, `RUNTIME_IMAGE`, `OCE_CHECKOUT` |
| `prepare-kustomize`           | Render one private Kustomize overlay stage from checked-in base files plus private inputs.               | `OCC_INPUT_DIRECTORY`, a stage name                                                                               |
| `prepare-slack`               | Enable the chart-managed Slack proxy and write its API and gateway inputs.                               | `OCC_INPUT_DIRECTORY`, `OCE_CHECKOUT`                                                                             |
| `prepare-shared-agent`        | Write a Configuration and credential-source request for a shared custom OpenAI endpoint.                 | `OCC_INPUT_DIRECTORY`, `MODEL_ID`, `OPENAI_BASE_URL`, `AGENT_NAME`, `MODEL_SECRET_RESPONSE_FILE`                  |
| `prepare-widget-preview`      | Write the public widget preview Route, certificate, and updated Installation and values.                 | `OCC_INPUT_DIRECTORY`, `OCE_CHECKOUT`, `OCC_NAMESPACE`, `AGENT_ID`                                                |
| `prepare-team-login`          | Render the team OAuth2 Proxy manifests and Gateway identity grants.                                      | `TEAM_LOGIN_DIRECTORY`, `CONFIGURATION_FILE`, `KUBECONFIG`                                                        |
| `prepare-team-login-users`    | Create missing realm accounts with per-account temporary passwords.                                      | `TEAM_LOGIN_DIRECTORY`, `TEAM_USERS_FILE`, `KEYCLOAK_*`                                                           |
| `add-agent-keycloak-client`   | Create one Agent's Keycloak client and membership group; write `settings.json`.                          | `TEAM_LOGIN_DIRECTORY`, `TEAM_USERS_FILE`, `TEAM_ADMIN_USERS_FILE`, `KEYCLOAK_*`, `AGENT_ID`                      |
| `create-team-login-realm`     | Create a new Keycloak realm with local accounts and a browser client.                                    | `TEAM_LOGIN_DIRECTORY`, `TEAM_USERS_FILE`, `TEAM_ADMIN_USERS_FILE`, `KEYCLOAK_*`, `AGENT_ID`                      |
| `configure-team-login-scopes` | Set the Keycloak scope-cap claim from the Gateway identity grants.                                       | `TEAM_LOGIN_DIRECTORY`, `KEYCLOAK_*`                                                                              |
| `configure-team-login-credit` | Set client-specific credit claims for saved users; preserve login identity and consent.                  | `TEAM_LOGIN_DIRECTORY`, `TEAM_CREDIT_USERS_FILE`, `KEYCLOAK_*`                                                    |
| `claw-links`                  | Print the human login Route URLs for private sharing.                                                    | `oc` context                                                                                                      |
| `build-occ`                   | Build the `occ` CLI into `deploy/rhoai/bin` from `OCE_CHECKOUT`.                                         | `OCE_CHECKOUT`                                                                                                    |
| `resolve-images`              | Pin the published OCE controller and runtime images by digest and write `images.env`.                    | `OCC_INPUT_DIRECTORY`, `OCE_CHECKOUT`                                                                             |
| `verify-images`               | Import-verify built ImageStreamTags and write `images.env`.                                              | `OCC_INPUT_DIRECTORY`                                                                                             |
| `resolve-runtime-source`      | Print the OpenClaw revision pinned by an OCE revision.                                                   | an OCE checkout and full OCE commit                                                                               |
| `build-images`                | Apply the in-cluster build templates and start controller and runtime builds **on the cluster**.         | `OCE_CHECKOUT`, `OCC_INPUT_DIRECTORY`                                                                             |
| `prepare-native-source`       | Archive a pinned OpenClaw commit with the child-stage build arguments the native runtime build needs.    | `OPENCLAW_CHECKOUT`, `OPENCLAW_COMMIT`, `OCC_INPUT_DIRECTORY`                                                     |
| `validate-installation`       | Load an Installation file with the release's startup loader.                                             | `OCE_CHECKOUT`, an absolute Installation path                                                                     |
| `grant-tenant-access`         | Bind the OCE identities in the discovered tenant namespace **on the cluster**.                           | `OCC_NAMESPACE`                                                                                                   |
| `upgrade`                     | Delegate to the selected OCE release's `upgrade-production-images` workflow **on the cluster**.          | `OCE_CHECKOUT`                                                                                                    |
| `openshell-mtls-post-render`  | Helm post-renderer that keeps the OpenShell gateway CA and its lifetime.                                 | none                                                                                                              |
| `dashboard-oidc-post-render`  | Helm post-renderer that resolves the dashboard OIDC issuer to the router Service ClusterIP.              | `KEYCLOAK_HOST`, `ROUTER_IP`                                                                                      |
